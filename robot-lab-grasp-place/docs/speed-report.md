# GraspNet 抓取提速报告（MuJoCo，2026-11-23）

本报告比较同一初始 MuJoCo 快照、同一腕部相机选点、同一 GraspNet 后端的两次**完整抓取并持物回零**。两次均通过抬升和回零后的持物确认。原始任务记录在测试机外部工作区：基线 `go2-grasp-1795445235088126944`，改后无录屏 `go2-grasp-1795445387606090703`；各任务的 `request.json`、`stage-timings.json`、`result.json` 可核对帧时间戳、阶段和结果。录像任务 `go2-grasp-1795445477713803479` 也成功，但持续渲染会影响速度，未用作对照。

## 改动范围

- `integration/integration/go2_grasp.py`：在用户选点前积累底盘静止窗口，预约后仍复核最新位姿与速度；启动时预热固定场景碰撞网格，按资源包、机器人配置和 TCP 指纹缓存并核对 STL 校验和，每个任务继续更新机器人与目标状态；提高仿真持物回零和空手预设动作的目标速度。
- `integration/integration/go2_grasp_ros.py`：记录每个抓取阶段的时间戳和接口耗时；缩短无负载预抓取轨迹时间，抬升阶段沿用原计划时间。
- `integration/integration/arm_trajectory.py`：取消 0.8／0.5 rad/s 的第二层保守软件上限，仍以导出模型的 **1.2 rad/s** 关节上限重定时。关节位置范围、碰撞和轨迹超时未取消；本改动不应视为真机驱动器限速配置。

## 从选点帧到实测首动

改后共 **5.735 秒**，基线 **6.167 秒**。改后各段：

- 帧到任务进程启动 0.873 秒；预检 0.366 秒；机器人预约 0.002 秒。
- 底盘稳定复核 0.104 秒；重新采集、校验和保存 RGB-D 合计 0.063 秒；模型导出及配置 0.100 秒。
- ROS 桥接 1.179 秒；节点启动到首批可用候选 1.773 秒；候选到 MoveIt 选定轨迹 0.937 秒；执行前新观测、发运动命令到实测首动 0.339 秒。

节点到首候选包含 ROS 节点启动、感知、GraspNet 推理、候选筛选与消息传递，不是纯模型推理时间。ROS 桥与节点仍按任务启动；本轮没有发布常驻 ROS 服务。

## 从首动到持物回零

- 预抓取运动：**4.905 → 3.397 秒**。
- 持物回零运动：**16.834 → 8.916 秒**。
- 从选点帧到完整抓取结束：**39.347 → 29.331 秒**，单轮减少 **10.016 秒（25.5%）**。
- 抬升后约 3.408 秒、回零后约 3.437 秒用于持物证据复核；没有为提速删除这两段确认。

另一轮只提高预设速度、尚未提高预抓取速度时，持物回零 8.956 秒、整轮 31.279 秒，抓取同样通过。最终速度配置的一次录像抓取也通过，33.9 秒 MP4 可在该任务目录查看；其选点帧到首动 7.785 秒，反映额外录像渲染负载，不能拿来估计代码退化。

## 已部署上一版如何增量更新

这次发布只替换上面三个抓取运行文件，不覆盖网页、场景 profile、放置代码、`config.local.json`、模型或现有运行目录。先确认当前仿真任务已结束，保存需要保留的现场；然后在已部署的 Robot Lab 宿主旁更新此仓库：

```bash
git -C piper-grasp pull --ff-only origin main
python3 piper-grasp/robot-lab-grasp-place/update_existing.py --host /path/to/robot-lab
python3 piper-grasp/robot-lab-grasp-place/update_existing.py --host /path/to/robot-lab --apply
```

第一条更新发布仓库，第二条只读核对旧版文件哈希，第三条备份并替换三个文件。如果宿主文件已被自行改动，工具会拒绝覆盖；请对照差异人工合并。按原部署方式重启**仿真抓取服务**后，重新采腕部 RGB-D 选点验证。启动后立即抓取可能尚在预热网格；比较速度时应等服务预热完成。旧版本回退可从更新工具打印的 `*-grasp-update-backup-*` 目录取回三份文件。

## 结论边界

以上为同一仿真场景的单轮前后对照，验证了这次 GraspNet 抓取与持物回零，未重测放置，也没有验证 GraspGenX 在提速后的完整抓放率。已有双算法 5/5 固定场景抓放记录属于本次改动前版本，不能算作本次新版验收。真机的关节限速、TCP、夹持证据与透明瓶稀疏深度仍需独立检查。
