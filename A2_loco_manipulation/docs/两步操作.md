# 现场监督：先靠近，再抓一次

这是复用现有靠近算法、原 a2.service 底盘服务及原 single_view 抓取流程的入口，不需要切换底盘服务。新底盘候选驱动不使用。

`--supervised` 明确选择人工现场监督：操作人确认观察姿态适合低速靠近、路径畅通、没有其他控制程序或遥控操作，现场可操作急停。程序检测其他 ROS 发布者、反馈过期和抓取时底盘移动后请求停止，但不能锁住遥控器/其他 DDS 来源；桥接进程本身被强杀或主机断电时，也不能承诺软件停止请求仍能送达。它不是之前宣称的全控制源独占模式。

## 一次准备

最新只读反馈为六关节全零，当前不符合停车参考对应的 J5=+5° 观察姿态。先处理夹爪里的物体并确认路径安全，再用工程已有工具准备姿态。以下第二条会实际使能、移动机械臂并张开夹爪，必须由现场操作人明确执行；助手本次没有执行：

```bash
cd /home/unitree/A2_loco_manipulation
./a2ctl observe-pose --execute
```

必须在统一驱动已经关闭时执行。若此前已 up，先结束当前任务并按恢复要求处理后 down；不要同时运行 SDK 工具和 ROS 驱动。本次检查结束时统一入口已 down，原底盘服务及外部相机未关闭。

等待姿态工具输出 READY，然后启动：

```bash
./a2ctl up
./a2ctl status
```

现场监督模式看 `environment_ready=true`、`supervised_control.available=true`、`supervised_control.fault` 为空和 `supervised_ready=true`。`observation_pose` 会显示实际角度和目标。旧 `ready` 是全控制源独占模式的就绪标志，仍为 false，不代表监督模式已获得硬件独占；目前 up 也会因此返回码 3，需依据上述监督字段区分。

## 第一段：靠近瓶子

仅在现场确认上述条件后执行：

```bash
./a2ctl run --supervised --task-id bottle-002 --goal bottle --timeout 300
./a2ctl status
```

使用已有瓶子检测、跟踪、深度和靠近控制器，不使用固定时长前进。速度转发限幅 x=0.10、y=0.05 m/s，转向 0.15 rad/s；停车参考沿用相机光学 Z<=0.54m。首次真实停车精度尚未验证，现场必须看守。

状态达到 AWAITING_PICK 才是第一段完成：导航结束、已验证连续实测停稳，程序等待你。第一段不会触发机械臂抓取。

## 第二段：确认后抓一次

在同一个 300 秒总时限内执行，使用同一个 ID：

```bash
./a2ctl pick-once --task-id bottle-002
./a2ctl status
```

继承第一段选择的监督模式，不重新导航。重新检查停稳与姿态，重新获取同一目标的新 RGB-D 数据，预览成功才使能并触发一次任务。过期数据、规划失败或反馈异常会拒绝；不能以 accepted 判断抓取成功。

HOLDING 表示“执行器报告持物保持”，现场确认瓶子。不会自动松爪、回零、重试或返回。

如你用其他方式已经到位，独立抓一次可使用 `pick-once --supervised --task-id 新ID`，同样需要现场监督与停稳、姿态、规划检查。

## 中止及异常

```bash
./a2ctl abort
./a2ctl status
```

软件中止不等于硬件急停。发生真实动作后的失败、超时或持物仍需现场处理并记录恢复，不能换 ID 或重启绕过。

旧 bottle-001 是此前在控制权预检阶段被拒绝的记录，已核对从未提交导航/抓取、当前执行器待机和底盘停稳后记录了这次拒绝的处理，原历史保留。它仍不能重复使用；本说明使用 bottle-002。没有对任何真实抓取后的恢复锁做自动清除。

## 本次验证边界

9 项监督转发模拟测试、17 项总控测试在本地及机载通过。机载无运动启动后，原底盘服务连接检查通过；连续 3 秒监测 /cmd_vel 和 /mode_switch 均为 0 条输出。TCP 实际值保持 0.105，接触阈值未改。尚未执行真实靠近、姿态准备或抓取，本说明不能替代现场低速验收。

日志：data/logs/unified/，监督桥接为 supervised.log。代码：scripts/unified/supervised_base.py。up 不发送速度，监督桥接只有在显式任务进入 navigation 后才转发；等待抓取/抓取时不再转发导航运动命令。原始独占模式与候选驱动保留，但不属于本操作流程。
