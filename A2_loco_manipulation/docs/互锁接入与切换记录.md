## 下一步具体只读验收

在用户明确同意暂停旧底盘服务后，由现场终端执行服务停止（需要 sudo 权限），再在前台运行：

```bash
sudo systemctl stop a2.service
cd /home/unitree/A2_loco_manipulation
bash scripts/unified/base-candidate-readonly.sh
```

此入口强制 allow_task_control=false，不发运动指令；若旧服务/进程仍在，会拒绝。它不会修改开机配置，不会打开真实导航许可。服务切换会暂时影响原有底盘 ROS 控制及反馈，需确认机器人当前静止、现场有人看守。

另开终端，只读检查候选的 /a2/odom、/a2_unified/base_status 与 ROS 图，确认旧命令订阅已经移除。结束候选时先在其前台 Ctrl+C，确认候选退出，然后才能恢复旧服务：

```bash
sudo systemctl start a2.service
```

不能同时运行两份底盘驱动。本轮尚未执行上述切换命令，也没有验证候选与实机的反馈链。

只读验收通过仍不等于可以运动：还需核验遥控器/其他 DDS 来源、机械臂行走姿态、控制程序崩溃时的实际底盘停止机制，并在明确授权后做低速停车与单次抓取测试。不把 ROS 命令独占宣称为所有物理控制源均被锁住。
